名刺やロゴに金や銀をきらっと光らせたい、と思ったことはありませんか？
箔押しは、データを「箔用の版下」として別に用意し、細い線・小さい文字・ぴったりの位置合わせを避けて作れば、初めてでもきれいに仕上げやすい加工です。
この記事では、箔押しのしくみと箔の種類、データの作り方、つぶれや欠けを防ぐコツ、入稿前のチェック表までを、印刷現場でなぜそうなるのかという理由とあわせて順番に紹介します。

## 箔押しとは？熱と圧で箔を写す加工

箔押し（はくおし）は、金属のような光沢のある薄いフィルム状の「箔」を、熱と圧力で紙に写し取る加工です。英語では「ホットスタンプ」とも呼ばれます。

しくみをかんたんに言うと、次のような流れです。

- 押したい形を彫った「版」を作る（金属の版が一般的で、金版（かなばん）と呼ばれることもあります）
- 版を加熱し、紙の上に箔を重ねる
- 版で上から押すと、版の形の部分だけ箔の接着層が溶けて紙にくっつく
- 箔のフィルムをはがすと、版の形に箔が残る

ハンコを押すイメージに近いのですが、インクではなく箔が転写されるのがポイントです。インクで金色を刷る「金インキ（特色の金）」と比べると、箔は鏡のような反射があり、光の当たり方で表情が変わります。
版の素材には金属のほか樹脂版を使う場合もあり、どの素材を使うかは印刷会社や加工の内容によって違います。版の素材を自分で選ぶ場面はあまりないので、「形ごとに専用の版を作る加工」と覚えておけば十分です。

また、版で強く押すため、紙が少しへこんで手ざわりにも表情が出ます。この凹みをあえて強めに出す仕上げを用意している会社もあります。

## 箔の種類と向いている印刷物

箔には色や質感の違うものがたくさんあります。代表的なものを一般的な特徴で並べると、次のようになります。

| 箔の種類 | 見た目の特徴 | 合いやすい雰囲気 |
|---|---|---|
| 金箔 | 黄みのある金属光沢。色味の違う金が何種類もあることが多い | 高級感、和の雰囲気、お祝い |
| 銀箔 | 白っぽい金属光沢。クールな印象 | モダン、シンプル、シャープ |
| 色箔 | 赤・青・ピンクなどの光沢のある色、またはつやを抑えた色 | ブランドカラーの強調、かわいらしさ |
| ホログラム箔 | 見る角度で虹色に変わる | 遊び心、ポップ、目立たせたい場所 |
| つや消し箔 | 光沢を抑えたしっとりした金属感 | 落ち着いた上品さ |
| 透明箔 | 色をつけず、光沢だけを足す | さりげない模様、紙の色を生かしたいとき |

※ここで挙げた名前は一般的な呼び方です。実際に選べる箔の色や品番は印刷会社によって違います。

箔押しがよく使われるのは、次のような印刷物です。

- 名刺・ショップカード（ロゴや名前だけを光らせる）
- 招待状・挨拶状（結婚式や記念行事など）
- パッケージ・化粧箱（ブランド名やロゴ）
- 冊子や本の表紙（タイトル文字）
- ロゴマークやシンボルを主役にした印刷物

共通しているのは、**光らせる部分が少なめで、見せたいものがはっきりしている**ことです。全体に散らすより、ロゴや名前など一点に絞ったほうが、箔の光がいちばん映えます。

## 箔押しのデータの作り方

箔押しで最初に押さえたいのは、**印刷用のデータとは別に「箔の形だけ」のデータを用意する**ことです。箔は版を作って押すため、印刷会社は「どこに箔を押すのか」を示す版下データ（版を作るための元データ）を必要とします。

一般的な作り方は次のとおりです。

1. 印刷用のデザインを作る（箔の部分は空けておくか、指定に従う）
2. 箔を押す部分だけを、別のレイヤー（Illustratorなどで重ねて管理する層）または別ファイルに分ける
3. 箔の部分を K100（黒インキ100%、ほかの色0%）のベタで塗る
4. 文字はアウトライン化（フォントの文字を図形に変換すること）しておく
5. 印刷データと箔データの位置がずれないよう、同じサイズのアートボード（作業画面の用紙枠）で、トンボ（仕上がり位置の目印）も共通にする

K100 で塗るのは、版を作るときに「ここが箔」「ここは箔なし」を白黒ではっきり判別するためです。箔の色がゴールドでも、データ上は黒で作ります。箔の色は、入稿時の指示や注文画面で別に指定するのが一般的です。

レイヤー名やファイル名の決まり（たとえば「箔」「foil」など）、別ファイルか別レイヤーか、トンボの付け方は、印刷会社ごとに決まっていることが多いので、注文先の入稿ガイドを先に開いておくと迷いません。

### データはベクターで作る

箔の版下は、拡大しても輪郭がなめらかなベクター形式（線や面を数式で表すデータ形式）で作るのが基本です。画像（ピクセルの集まり）だと、輪郭がギザギザになったり、ぼやけた部分が箔になるのかならないのかあいまいになったりします。

### AIで作ったロゴを箔にしたいとき

画像生成AIで作ったロゴは、多くの場合 PNG や JPEG などの画像で出てきます。このままでは輪郭がにじんでいたり、グラデーションや影がついていたりして、箔の版下にはそのまま使いにくいことがほとんどです。

箔に使うなら、次のように整えておくと安心です。

- Illustrator の画像トレースなどでベクターに変換する
- トレースでできたガタガタの輪郭や不要な点を手で整える
- グラデーション・影・細かい質感を取り除き、「箔にする／しない」の2択の形にする
- 線の太さや文字の大きさが、次の章の目安に収まっているか確かめる

AIでロゴを作る流れや、清書のしかたは[画像生成AIでロゴを作る手順](ai-logo-howto.html)で詳しく紹介しています。箔押しを予定しているなら、清書の段階で「1色のベタで成り立つ形か」を意識しておくと、あとの作業がぐっと楽になります。

## 細い線・小さい文字・ベタ面が苦手な理由

箔押しは、熱した版で箔を押しつけて写す加工です。そのため、インクで刷る印刷よりも細かい表現が苦手です。理由を知っておくと、デザインの段階で避けやすくなります。

### 細い線・小さい文字は欠けやすい

線が細すぎると、版で押したときに箔が紙にくっつく面積が足りず、線がとぎれたり欠けたりしやすくなります。小さい文字も同じで、とくに明朝体の横線のような細い部分から欠けていきます。

逆に、線と線のすき間が狭すぎると、そのすき間まで箔がついて埋まってしまうことがあります。画数の多い漢字を小さく押すと、文字がつぶれて読みにくくなるのはこのためです。

目安として、線の太さはおおむね 0.2〜0.3mm 以上、文字は 7〜8pt 前後以上を案内している印刷会社が多い印象です。ただし、箔の種類や紙、加工方法で下限は変わり、**正確な数値は印刷会社によって違います**。注文先の入稿ガイドに書かれた数値を確認してから作るのがいちばん確実です。
また、まわりを箔で塗って文字を紙の色で残す「抜き文字」は、通常の文字よりつぶれやすいため、さらに太め・大きめにしておくと安心です。

### 網点・グラデーションは表現できない

箔は「押すか、押さないか」の2択です。インクのように濃い・薄いを細かい点の大きさで表す網点（あみてん）や、なめらかなグラデーションは基本的に再現できません。グレーの部分は、箔になるか消えるかのどちらかになってしまいます。
濃淡を出したい場合は、細かいグラデーションではなく、太めの線や模様の密度で表現するなど、形そのものを工夫するのが向いています。

### 大きなベタ面はムラ・気泡が出やすい

面積の広いベタ（すき間なく塗りつぶした部分）は、全体に均一な熱と圧をかけるのが難しく、箔のつきが部分的に弱くなるムラや、空気が入ったような小さな気泡・かすれが出ることがあります。
大きな面に箔を入れたい場合は、面積を少し小さくする、模様で区切るなどの工夫をするか、入稿前に印刷会社へ相談しておくと仕上がりのイメージを合わせやすくなります。

## 印刷との位置ズレを前提にしたデザイン

箔押しは多くの場合、先にインクで印刷し、そのあと別の機械で箔を押します。工程が分かれるため、印刷と箔の位置には「見当ズレ」（重なる位置のわずかなずれ）が起こります。ずれの幅は一般に1ミリに満たない程度ですが、ぴったり合わせたデザインほど目立ちます。

ずれても目立ちにくくするコツは、次の3つです。

- **箔と印刷をぴったり接しさせない**：箔の文字を印刷の枠ぴったりに収める、といった配置は、少しずれただけで片側にすき間、反対側に重なりが出ます
- **少し離す**：箔と印刷部分の間に余白をとると、ずれても「余白の幅が少し変わった」程度にしか見えません
- **あえて重ねる**：印刷の色面の上に箔をのせる場合は、印刷側の面を箔より少し大きめにしておくと、ずれても下地がはみ出しにくくなります

どのくらい離す・重ねるのがよいかは、加工の精度や印刷会社の推奨によって違います。入稿ガイドに数値が書かれていれば、それに合わせておきましょう。

また、断裁（仕上がりサイズに切ること）の位置にもずれがあります。仕上がり線のすぐ近くに箔を置くと、切れたり端に寄って見えたりしやすいので、ふつうの文字と同じように、仕上がり線から内側に余裕をもたせておくと安心です。名刺の安全な文字位置については、[AIで名刺デザインを作って印刷するまで](ai-business-card-print.html)でも紹介しています。

## 紙・ほかの加工との相性と、コスト・納期の考え方

### 紙との相性

箔は紙の表面に押しつけてくっつけるため、紙の表面の状態で仕上がりが変わります。

- **表面がなめらかな紙**：箔が均一につきやすく、細かい形も出しやすい傾向があります
- **凹凸の強い紙（エンボス紙・ざらっとした風合いの紙など）**：へこんだ部分に箔が届きにくく、かすれたり欠けたりしやすくなります。風合いを生かした仕上がりになる一方、細かい文字には不向きなことが多いです
- **色の濃い紙**：金や銀の箔が映えやすく、印刷では出せない「紙に光る色をのせる」表現ができます

### PP加工やほかの加工と組み合わせるとき

PP加工（紙の表面に薄いフィルムを貼る加工）の上に箔を押すこともあります。この場合は、フィルムの種類によって箔のつきやすさが変わるため、対応しているかどうかや注意点を印刷会社に確かめておくとスムーズです。
表面加工の種類については[表面加工の種類と選び方](surface-finishing-types.html)、部分的につやを出す加工については[UV加工・スポットUVの基本](uv-spot-coating-basics.html)もあわせて読むと、箔とどう組み合わせるか考えやすくなります。

### 版代と納期

箔押しは、デザインごとに専用の版を作ります。そのため、印刷代とは別に版を作る費用（版代）がかかるのが一般的です。版代は枚数が少なくても多くても同じようにかかるので、**小ロットだと1枚あたりが割高になりやすく**、枚数が増えるほど1枚あたりの負担は小さくなります。

また、印刷とは別の工程が加わるため、通常の印刷より納期が長くなりやすいです。イベントや配布日が決まっている場合は、余裕をもったスケジュールで注文しておくと落ち着いて準備できます。
同じロゴで何度も注文する場合、版を保管して再利用できるサービスを用意している会社もあります。

### 版を作らない「デジタル箔」という方法も

近年は、版を作らずに箔を表現する方法も広がっています。たとえば、トナー（レーザープリンターなどの粉状のインク）の上に熱で箔を貼りつける「トナー箔」や、専用の機械でデータから直接箔をのせる「デジタル箔」と呼ばれる方法です。
版が要らないため、少ない枚数や、1枚ずつ名前を変えたい場合に向いていることがあります。一方で、手ざわりの凹み、使える箔の種類、仕上がりの質感は、版で押す箔押しとは違うことがあります。呼び方や対応範囲はサービスによってさまざまなので、作例や説明をよく見て選ぶと、イメージどおりに仕上がりやすくなります。

## 入稿前のチェック表

データができたら、入稿前に次の表で確かめてみてください。ひとつずつ確認すれば、数分で見直せます。

| 確認すること | 見るポイント |
|---|---|
| 箔データの分け方 | 印刷用とは別レイヤー（または別ファイル）になっているか、名前は入稿ガイドどおりか |
| 箔データの色 | K100 のベタになっているか（グレーや網点が混ざっていないか） |
| 形式 | ベクターになっているか、文字はアウトライン化したか |
| 位置合わせ | 印刷データと同じサイズ・同じトンボで、箔の位置がそろっているか |
| 線の太さ・文字サイズ | 入稿ガイドの下限を下回っていないか（抜き文字は特に余裕をもって） |
| すき間 | 線と線、文字の中のすき間が狭すぎて埋まりそうな部分はないか |
| ベタの大きさ | 大きな面がある場合、ムラについて確認・相談したか |
| 印刷との境目 | 箔と印刷がぴったり接していないか（離すか重ねるか決めたか） |
| 仕上がり線からの距離 | 箔が断裁位置に近すぎないか |
| 紙・表面加工 | 凹凸の強い紙や PP 加工と組み合わせる場合、対応を確認したか |
| 箔の色の指定 | 注文画面や指示書で箔の種類・色を指定したか |
| スケジュール | 箔押し分の納期を見込んで注文日を決めたか |

迷う点があれば、入稿前に印刷会社へ問い合わせるのがいちばん早い解決策です。データを見たうえで具体的にアドバイスしてくれる会社も多くあります。

## まとめ

箔押しは、熱と圧で箔を写すことで、インクでは出せない光や手ざわりを加えられる加工です。きれいに仕上げるポイントをもう一度並べます。

- 箔の部分は印刷用とは別のレイヤーかファイルに分け、K100・ベクターで作る
- AIで作ったロゴは、ベクター化して1色のベタで成り立つ形に整える
- 細い線・小さい文字・狭いすき間・網点・グラデーションは避け、下限は入稿ガイドで確認する
- 大きなベタ面はムラが出やすいので、形を工夫するか事前に相談する
- 印刷とはぴったり接しさせず、少し離すか重ねて見当ズレに備える
- 版代と工程が加わるため、小ロットは割高に、納期は長めになりやすい
- 少部数ならデジタル箔のような方法も選択肢になる

まずは、手元のロゴや名前のデータを1つ開いて、「この形を K100 の1色だけで表せるか」を試してみてください。それだけで、箔押しに向いているかどうかがすぐに見えてきます。
